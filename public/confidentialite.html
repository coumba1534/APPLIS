Confidentialité

Appli Khatm · mise à jour le 26 novembre 2026

Khatm aide à lire le Coran en entier, seul ou en groupe. L'appli enregistre le moins de choses possible. Il n'y a ni publicité, ni statistiques de visite, ni revente de données, et aucune adresse e-mail ni numéro de téléphone n'est demandé.

Ce qui reste sur votre téléphone

Votre prénom, si vous êtes une femme ou un homme, votre khatm, votre progression, votre marque-page et vos réglages sont enregistrés sur votre téléphone. Ils y restent tant que l'appli est installée.

Les groupes

Si vous créez ou rejoignez un groupe, ces informations sont enregistrées chez Google Firebase (serveurs en Belgique) :

  • votre prénom, si vous êtes une femme ou un homme (pour que les groupes ne soient pas mixtes), et les jours que vous avez lus ;
  • le nom du groupe, son code d'invitation et les demandes pour y entrer.

Les membres du groupe voient le prénom et la progression des autres membres. Dans un groupe encadré, chaque membre ne voit que sa section (sœurs ou frères) ; l'oustaz ou l'oustaza voit les deux. Pour cela, l'appli se connecte de façon anonyme : un identifiant au hasard, sans nom, e-mail ni numéro.

Ces informations restent tant que le groupe existe. Quand vous quittez un groupe, vous n'en faites plus partie.

La sauvegarde et le code personnel

Votre progression est sauvegardée automatiquement chez Google Firebase, pour pouvoir la retrouver sur un nouveau téléphone. Elle est chiffrée sur votre téléphone avec votre code personnel avant d'être envoyée : sans ce code, personne ne peut la lire, pas même nous. Gardez ce code pour vous.

Les rappels

Si vous autorisez les rappels, ils sont envoyés par un service installé chez Cloudflare. Il garde :

  • l'adresse technique de votre téléphone pour les notifications (donnée par Apple ou Google, elle ne dit pas qui vous êtes) ;
  • la liste de vos rappels des 14 prochains jours, par exemple « Après Fajr · Juz 3, pages 41 à 50 » ;
  • un journal des envois, effacé au bout de 7 jours.

Si vous désinstallez l'appli ou bloquez les notifications, votre téléphone est retiré automatiquement de la liste.

Les autres services utilisés

  • L'appli est hébergée par GitHub Pages.
  • Les polices d'écriture sont chargées depuis Google Fonts.

Comme pour tout site internet, ces services voient passer l'adresse internet (IP) de votre téléphone quand ils lui envoient les fichiers.

Tout effacer

  • Quitter un groupe : onglet Groupe, « Quitter le groupe ».
  • Effacer ce qui est sur le téléphone et les rappels : désinstaller l'appli.
  • Effacer votre sauvegarde ou toute autre information : écrivez-nous (adresse ci-dessous) en indiquant votre code personnel. Nous l'effacerons.
